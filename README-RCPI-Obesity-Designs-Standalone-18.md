# RCPI Obesity Designs Standalone

> **File:** `RCPI-Obesity-Designs-Standalone.user-18.js`  
> **Version:** unknown

## Overview

A standalone panel for loading and inserting RCPI Obesity programme-specific design components into Brightspace content pages. Functions similarly to the Block Builder Standalone but targeted at a specific design set for the Obesity course.

## Features

- Floating action button to open the Obesity designs panel
- Loads RCPI Obesity design components in a side iframe
- Allows drag-and-drop or copy-paste of components into the TinyMCE editor
- Panel width is resizable and persisted

## Usage

Install via Tampermonkey. Open a content topic in edit mode. Click the Obesity Designs FAB to open the panel and access course-specific design components.

## Notes

- Matches `https://brightspace.rcpi.ie/*`.
- Intended for use by RCPI instructional designers working on the Obesity programme.
